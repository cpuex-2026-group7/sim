# sim
Simulator written in C++

## Build
```bash
make
```

## Usage
```bash
./build/sim <path_to_binary> [--trace <path>] [--in <path>] [--out <path>] [--cache-stats] [--branch-stats]
./build/sim --boot [--trace <path>] [--in <path>] [--out <path>] [--cache-stats] [--branch-stats]
```

## Requirements
- clang++
